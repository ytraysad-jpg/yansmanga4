# YansManga

Starter website katalog manga dengan React, TypeScript, Vite, dan MangaDex API.

## Menjalankan di laptop
1. Install Node.js LTS.
2. Ekstrak ZIP dan buka folder ini di VS Code.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.

## Menjalankan di HP
Unggah folder proyek ke GitHub, lalu buka StackBlitz dan impor repository. Alternatifnya, gunakan editor online yang mendukung proyek Vite.

## Catatan
- Data judul dan cover diambil langsung dari MangaDex API.
- Favorit dan riwayat disimpan di localStorage browser.
- Reader chapter belum termasuk tahap awal ini.
- YansManga bukan afiliasi resmi MangaDex. Hormati hak cipta dan ketentuan sumber konten.
